# Приемочный чек-лист

Используется после настройки локального стенда. Отмечайте только действительно проверенные пункты. Для подробностей см. [тест-кейсы](TEST_CASES.md).

- [ ] Приложение запустилось; вход под оператором работает.
- [ ] Без авторизации служебный API возвращает 401.
- [ ] Открываются главная и все пункты основного меню.
- [ ] Сотрудник создается и сохраняется после обновления страницы.
- [ ] Дублирующийся табельный номер отклоняется.
- [ ] Новая партия СИЗ создает карточки с уникальными номерами.
- [ ] К карточке СИЗ доступны печатный документ и штрихкод.
- [ ] Ведомость выдачи формируется и подтверждается; получатель появляется в карточке.
- [ ] Просроченный СИЗ не выдается.
- [ ] Подписанное списание меняет статус изделия.
- [ ] Утилизация зарегистрирована; повторная передача запрещена.
- [ ] Состав НФГО совпадает с данными общего справочника.
- [ ] Внутреннее оповещение звена появляется в уведомлениях.
- [ ] Вместимость укрытия проверяется; история проверок доступна.
- [ ] Автоматическое распределение эвакуации учитывает места.
- [ ] Приказ НФГО формируется и выгружается в Word.
- [ ] Отчет НФГО открывается и выгружается в Excel/XML.
- [ ] Журнал сохраняет занятие, посещаемость и результаты.
- [ ] Подписанное занятие защищено от прямого редактирования.
- [ ] Сводка журнала различает пороги 12 и 15 часов.
- [ ] Пятилетний план закупок показывает годы и суммы.
- [ ] Приказ военного режима создается, подписывается и отображает правильное время.
- [ ] При активации приказа режим меняется и обычный отпуск запрещается.
- [ ] Интеграционный автотест запущен и результат сохранен либо честно указан NOT RUN.
- [ ] Браузерный автотест запущен и результат сохранен либо честно указан NOT RUN.
- [ ] Нагрузочные проверки выполнены либо честно указаны NOT RUN.
- [ ] Выявленные ошибки занесены в журнал дефектов.
