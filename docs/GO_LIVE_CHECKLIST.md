# Go-live checklist системы ГОЧС

> Не отмечайте пункт как выполненный без фактической проверки.

## A. Управление

- [ ] Назначен владелец системы.
- [ ] Назначен администратор.
- [ ] Назначен основной оператор.
- [ ] Назначен резервный оператор.
- [ ] Определён канал поддержки.
- [ ] Согласованы известные ограничения.
- [ ] Утверждена версия/commit.

## B. Инфраструктура

- [ ] Сервер готов.
- [ ] DNS настроен.
- [ ] HTTPS настроен.
- [ ] Network access ограничен.
- [ ] Дисковое пространство проверено.
- [ ] Persistent volumes созданы.
- [ ] Внешнее хранение backup определено.
- [ ] Системное время проверено.

## C. Конфигурация

- [ ] Пароль не хранится в `.env`.
- [ ] `DOMAIN` задан точно.
- [ ] `TrustedProxy` задан.
- [ ] `AllowedHosts` не содержит `*`.
- [ ] Пароль не короче 16 символов.
- [ ] Secret file защищён правами.
- [ ] Swagger отключён для server mode.
- [ ] Срок сессии согласован.

## D. Запуск

- [ ] Compose config проходит проверку.
- [ ] Контейнеры запущены.
- [ ] `/api/health` = 200.
- [ ] HTTPS работает.
- [ ] Вход работает.
- [ ] После logout API = 401.
- [ ] Secure/HttpOnly/SameSite cookie проверены.

## E. Данные

- [ ] Организация корректна.
- [ ] Сотрудники проверены.
- [ ] Табельные номера уникальны.
- [ ] Склады проверены.
- [ ] Типы СИЗ и цены проверены.
- [ ] НФГО проверено.
- [ ] Укрытия проверены.
- [ ] Транспорт и пункты проверены.
- [ ] Учебные группы проверены.
- [ ] Контрагенты проверены.

## F. Business smoke-test

- [ ] Dashboard.
- [ ] Сотрудники.
- [ ] Реестр СИЗ.
- [ ] Карточки.
- [ ] Выдача.
- [ ] Списание.
- [ ] Утилизация.
- [ ] Эвакуация.
- [ ] НФГО.
- [ ] Защитные сооружения.
- [ ] Журнал.
- [ ] Приказы.
- [ ] План закупок.
- [ ] Отчёт НФГО.
- [ ] Режим.
- [ ] Аналитика.
- [ ] Уведомления.

## G. Документы

- [ ] HTML export.
- [ ] DOCX открывается.
- [ ] XLSX открывается.
- [ ] XML валиден.
- [ ] Печать/PDF проверена.
- [ ] Организация в документах корректна.

## H. Backup / restore

- [ ] Backup до запуска создан.
- [ ] Копия вынесена за рабочий volume.
- [ ] Integrity check успешен.
- [ ] Restore выполнен на отдельном стенде.
- [ ] RPO/RTO согласованы.

## I. Тестирование

- [ ] Integration test выполнен.
- [ ] UI test выполнен.
- [ ] Результаты сохранены.
- [ ] Нет критических дефектов.
- [ ] `TEST_REPORT.md` заполнен.
- [ ] Acceptance checklist заполнен.

## J. Обучение

- [ ] Основной оператор обучен.
- [ ] Резервный оператор обучен.
- [ ] Контрольный сценарий выполнен.
- [ ] Руководство выдано.
- [ ] Канал поддержки известен.
- [ ] Пользователь знает: подпись != УКЭП.

## K. Старт

- [ ] Зафиксировано время go-live.
- [ ] Зафиксирован commit/version.
- [ ] Необязательные изменения заморожены.
- [ ] Назначен hypercare.
- [ ] Первый production backup создан.
- [ ] Restart выполнен, данные сохранились.

## L. После запуска

### Первый день

- [ ] Health стабилен.
- [ ] Нет P1/P2 либо есть утверждённый план.
- [ ] Backup создан.
- [ ] Пользователи вошли.
- [ ] Основные операции выполняются.

### Через 5 рабочих дней

- [ ] Hypercare завершён или продлён.
- [ ] P1/P2 закрыты или имеют план.
- [ ] Повторяющиеся пользовательские ошибки разобраны.
- [ ] Документация уточнена.
- [ ] Система передана в штатную поддержку.
