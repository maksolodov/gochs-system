# ГОЧС

Учебная информационная система для учета и планирования мероприятий гражданской обороны и защиты от чрезвычайных ситуаций.

## Возможности

- Общий справочник сотрудников, НФГО, укрытий и транспорта.
- Учет СИЗ: поступление, выдача, списание и утилизация.
- Планирование эвакуации и закупок.
- Журнал занятий, приказы, отчеты и выгрузка документов.
- Вход оператора, история действий и вложения.

Стек: .NET 8, ASP.NET Core 8, Entity Framework Core 8, SQLite, HTML/CSS/JavaScript. Все модули используют одну базу.

## Запуск через Docker

Требуется Docker с плагином Compose. Из корня репозитория:

```sh
docker compose up --build -d
```

Приложение: http://127.0.0.1:5080. Swagger: http://127.0.0.1:5080/swagger, после входа в том же браузере.

Пароль оператора создается при первом запуске:

```sh
docker compose exec gochs cat /app/data/operator-password.txt
```

Остановка: `docker compose down`. Данные сохраняются в томе `gochs-data`; не добавляйте `-v`, если они нужны.

## Запуск без Docker

Требуется .NET 8 SDK. Из корня репозитория:

```sh
cd backend
dotnet run -- --urls http://127.0.0.1:5080
```

Адрес приложения и Swagger тот же. Для входа укажите свое имя и пароль из `data/operator-password.txt` в корне репозитория. Остановка - Ctrl+C.

База находится в `data/gochs.db`. Демонстрационные данные создаются только при первом запуске пустой базы. Изменения схемы применяются автоматически с резервным копированием существующих данных.

## Проверки и документация

```sh
python tests/integration.py
npm install
npm run test:ui
```

Для тестов нужны Python 3, Node.js и Edge. Тесты сами собирают приложение и используют отдельные временные базы. `DOTNET` позволяет указать путь к SDK, если он отсутствует в PATH.
